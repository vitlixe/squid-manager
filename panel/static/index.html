How to use
  • Add user: Fill in the form (last name, first name, middle name, status) and click Add. The new login and password are shown after creation.
  • Search: Use the search field above the list to filter by name or login.
  • Show/hide password: The button toggles the password.
  • Copy credentials: The button copies the login and password to the clipboard.
  • Reset password: The button generates a new password and shows it in a popup.
  • Delete user: The button deletes the user after confirmation.
Important! After all changes, click Reload Squid to apply them.
